## Safety notes

- app-shelf-launch-routing-smoke selects a real visible native .desktop entry from the promoted App Shelf inventory and launches it inside the nested mobile session
- the selected app is observed alive briefly, then the smoke terminates only the process it started and verifies no residual launched process
- the smoke does not enable autostart, use layer-shell, mutate the host compositor, read notifications, invoke tools/models, or write persistent Shell files
