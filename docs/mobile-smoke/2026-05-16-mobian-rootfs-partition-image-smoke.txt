Notes:

- The first implementation attempt surfaced a real tool boundary: Android SDK mke2fs was built without libarchive, so it cannot populate an ext4 image directly from a tarball.
- The promoted path therefore extracts the already verified rootfs tarball into a temporary rootfs directory and uses mke2fs directory population.
- Rootless extraction cannot create device nodes such as /dev/null. The smoke explicitly skips rootfs /dev device nodes, keeps /dev as a mount point, and records that boot-time devtmpfs is required.
- This is a real ext4 rootfs partition image artifact. It is still not a full bootable disk image, emulator boot, phone flash, OTA, recovery, repartition, or reboot proof.
