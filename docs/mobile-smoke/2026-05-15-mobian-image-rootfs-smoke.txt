Notes:

- The first attempts surfaced two real host boundaries: rootless mmdebstrap could not create a rootfs under the workspace path from its user namespace, and the host lacked a Debian archive keyring new enough for current Bookworm/Trixie signing subkeys.
- The promoted smoke builds the work root under /tmp, requires a Debian archive keyring without disabling apt signature verification, builds the Trillionnium .deb payloads through the package install smoke, and passes them into mmdebstrap with file-mirror-automount so dpkg installs them inside the image chroot.
- This is a real rootfs tarball build with Trillionnium packages installed into the generated Mobian/Phosh rootfs. It is still not a flashable disk image, emulator boot, phone flash, OTA, recovery, repartition, or reboot proof.
