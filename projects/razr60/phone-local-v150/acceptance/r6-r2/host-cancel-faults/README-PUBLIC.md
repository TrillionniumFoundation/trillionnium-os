# Host fault source and quality checkpoint publication

This directory is an explicit publication allowlist, not a copy of private execution evidence.

The six fixture source files are original sealed bytes. They ran only in a private host user/mount/PID/network namespace against the original frozen provider and a deterministic local HTTP fixture. Actual Android commands were recorded, never executed. The five host cases passed 151 assertions across five samples, with actual inner elapsed 6.542 seconds; they do not establish phone, native Host, SELinux, real model, or model-server drain qualification.

The inner one-shot 90-second alarm can be caught by the per-case exception handler. The recorded sample did not trigger it; the independent outer owned process bound remains documented. No post-hoc source change or rerun is represented here.

Quality checkpoint 02 retains the same r6-r2 combination: 7 fixed cases PASS, 3 FAIL, 9 BLOCKED. Fifteen executed samples are distinct from 33 declaration rows that retain historical not-run placeholders. Two model business attempts failed; one health attempt passed independently. The physical NEG-08 request was truly cancelled with zero tools and a joined HTTP client, but its original server slot remained busy. Its physical FAIL is retained despite successful host cancellation fixtures and subsequent safe restoration of the user's draft and retirement of the old service.

Only sources and redacted metadata are included. Original request text, nonce, draft, key material or key digests, claims, native records, screenshots, execution-instance directories, and private operation captures are excluded. Exact original artifact hashes are provenance only. No file here authorizes a new Send, replay, deployment, or service start.
