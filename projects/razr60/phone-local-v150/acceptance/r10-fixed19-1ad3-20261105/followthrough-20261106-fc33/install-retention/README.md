## What is implemented

The actual stage authority must be established from the reviewed BUILD reader, projected actual installer/archive, exact execution plan, source guard, original actor process request/start/status/read, private request/intent/baseline/result, and full phone streams. The host module reuses the selected original install reader's granular phase verification. It does not call the full installation/READY gate prematurely.

From that actual stage stdout it derives the exact saved-file bytes for INSTALL-INTENT.json and STAGED.json, and the complete bytes/SHA pin for STAGED-PRESERVATION.original.json. For start it derives START-INTENT.json and STARTED.json and binds the actual supervisor pid/pgrp/session/startticks tuple from the original STARTED stdout. A stage scope has no new supervisor generation. A started tuple is not a claim that the supervisor remains live, is ready, or has been waited.

The phone producer accepts only those three stage roles or two start roles at their exact existing GNU paths. It opens every directory component with O_NOFOLLOW, then holds the installation directory FD. Each selected source file must be root-owned, mode0600, regular and single-link. It streams the whole selected file to verify its size/SHA and file/directory full9 bookends, while retaining only the requested 1MiB slice in memory.

The sequence is first manifest, all exact file/index chunks, final manifest. Each chunk binds the entire first manifest, exact original full9, scope and complete file pin. The final manifest must repeat all original file bytes/full9 and directory full9. The host rejects missing, extra, repeated, reordered, truncated, noncanonical or mismatched chunks and reconstructs the complete original bytes before it writes retained files.

The entire reviewed producer body, exact bound scope and operation are embedded in an independently derived original actor request. There is no new on-phone producer file to publish. The full GNU environment comes from the existing reviewed v2 protocol. Complete actor originals verify the exact submitted inline source/arguments and integer phone exit0. The producer reports two same-process raw proc observations and checks its actual boot. It has a 30s own-process deadline and a bounded stdout write; the original shell cap remains 8MiB and the original ADB service limit remains below65536 bytes. The selected operation timeout is120s, within the existing300s actor ceiling.

The host publisher holds a newly created directory FD, validates dev/ino/mode/uid/gid plus the exact member set, uses relative O_EXCL/O_NOFOLLOW operations, verifies complete readback/full9, fsyncs, and writes RETENTION-RESULT.json last.
