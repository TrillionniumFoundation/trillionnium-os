# R8 NEG01 / NEG02 plan helper for compact parent combination

This source-only subpackage differs from the retained 68df helper only in `FREEZER_TEMPLATE_SHA`. It accepts the new compact-combination freezer plus its single explicit FINALIZATION literal. It does not accept the old 62bc freezer as an alternative. All actual freeze-output, Root3/runtime32, history, identity, request, role and source checks remain byte-identical.

The actual completed R8 FREEZE-RESULT and caller-selected one-use identity are required. Neither is generated by this package. The default runs read-only validation; --execute-host-plan writes a fresh host plan only.

CLI: `/usr/bin/python3 -I -B source/prepare_native_guard_root_plan.py --inputs-desc '<exact3 descriptor>' [--execute-host-plan]`.

Templates remain unfilled. No actual plan validation, phone call, native submission or acceptance qualification was performed locally.
