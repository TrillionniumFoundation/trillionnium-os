# r7 business capture, export and collection

This operator is for Root after one actual new visual or Unicode task. It never generates a nonce, registers, sends, cancels, contacts the model or executor, changes a service, or reads keys or preserved drafts. It selects the exact original owner request and five-field scope from existing sender evidence.

The phone snapshot pins all 13 production sources from provider-r7, the configuration, service inputs and original r6 client. It retains the complete original provider run, including raw HTTP response, model-action, mapping and legacy decision files, the actual selected native records, one-use contract/claim/binding, r6 action intent/receipt/stdout/stderr and client transport records. The old 64 MiB archive, file-count and time bounds remain.

Root supplies existing material, sender label and one new output directory. Run the same arguments through these four phases:
    python3 -B export_business_once.py preview --material <existing-r7-material> --sender-label <actual-label> --out <new-private-output>
    python3 -B export_business_once.py capture --material <existing-r7-material> --sender-label <actual-label> --out <same-output> --execute-read-once
    python3 -B export_business_once.py export --material <existing-r7-material> --sender-label <actual-label> --out <same-output> --execute-read-once
    python3 -B export_business_once.py collect --material <existing-r7-material> --sender-label <actual-label> --out <same-output>

preview and collect are host-only; capture/export are separately bounded Root-only original reads. A failed or unknown capture is inspected through its original operation, never resubmitted with another nonce. Partial archives remain available for diagnosis. No status is upgraded from its raw report alone: complete original capture, original capture actor and phone zero exits, real collector exit zero, and original business predicates all remain required.

The collector now independently checks exact original named model object to legacy action projection. Its fourth dependency mobile_use_evidence.py is explicitly pinned. Projection correctness is not a business result. Native raw streams, executor identity/credentials/cleanup, no-replay ledger and whole-request postconditions remain unchanged. Every original failed/cancelled/partial outcome is retained. These support source checks are not fixed19 or phone qualification.
