# Code21：历史、重复动作与中断会话恢复

本次公开源码在完整 Code20 基础上加入有序动作历史、准确的应用查询来源、同一可观测状态下的无变化动作保护，以及由真实用户按钮确认的中断会话恢复。原有 MobiMind、UI-Venus、共享模型槽与诊断启动屏障保留。恢复归档保留旧任务、原 native 记录及未知的旧清理状态，新的可用会话另有哈希绑定的确认事务；不会自动续跑旧任务。

## 已完成的构建验证

实际私有构建完成 Linux 原始 62/62 宿主门、真实 Android Java/DEX/NDK 编译与原签名组装；17 个 native 成员与 Code20 完全相同。初次 SDK API 错误、Mac 平台夹具失败和早期 handoff 路径错误均保留在构建摘要中。完整 Linux 通过记录作为后续独立资格证据，未改写较早的准备回执。

CI v8 对本次公开源码重新运行原宿主门和 Android 构建。新增的 UI-Venus 流程在 macOS 执行原构建器，要求新 worker 与固定原文件完整相等，并把真实新构建回执绑定到本次 Git HEAD、workflow run 和 attempt 后交给 Linux 复核。原历史构建回执保持历史身份。该公开提交的 CI 结果以其确切 HEAD 的真实运行记录为准，11 个离线传输契约通过不等于 CI 已执行编译。

构建资格不证明手机任务、普通入口、停止或恢复验收通过。手机原判定与证据资格由独立验收记录说明；Code22 的 MoE 变更不包含在本次源码中。
