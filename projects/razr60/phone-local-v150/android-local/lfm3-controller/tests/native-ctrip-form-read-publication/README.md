# Same-current-form post-encoding publication

This finite host test compiles the actual production observation bodies, full Ctrip comparator,
profile value classes and diagnostics. It uses explicitly synthetic Android graph/window/pixel,
event and clock ports. It grants no action or business authority.

The positive case samples A=A, captures pixels, verifies complete B=A, then reads complete C
after a known target content event. Only differences accepted by the existing full form
classifier may yield a historical form publication. The original capture time, request deadline,
full sidecar digest, publication watermark and all ownership checks remain.

The negative cases cover protected fields, overlap, omissions, owner/user/window/display changes,
unknown/boundary/late events, replaced current read, cancellation and expiry. Diagnostics retain
one immutable bounded latest decision; no extra traversal or larger cap is used.

Run from a complete source export:

    python3 -B tests/native-ctrip-form-read-publication/run_host.py \
      --source SOURCE --output NEW_OUTPUT --java-home JDK17 --json-jar JSON_JAR

An optional private archive replay accepts --actual-census and --actual-census-sha256. It reads
all unchanged native node values from that already collected complete pair. Its synthetic
event timing and Android authority are not the original device watermark and cannot establish
that the historical failure would have published. The private archive is never copied into
this public test directory. The existing 68-case observer suite is not executed by this runner.

The original entered-OPEN synthetic fixture is exercised only by the public run. Its fixed
synthetic native window cannot be mixed with the private pair's actual window identity. Private
mode runs the ordinary-read finite cases with that complete pair and explicitly synthetic ports;
it does not re-label the old entered-OPEN fixture as private evidence.
