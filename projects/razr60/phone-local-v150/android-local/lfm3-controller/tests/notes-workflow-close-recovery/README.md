## Inputs and privacy

The Java test and runner are public parameterized source. The external input map must supply exactly 23 byte-exact historical originals and additional current control, with each absolute path, size and SHA-256. Private phone files, their map and generated results remain outside the repository. This gate cannot run without them and is not a self-contained synthetic fixture.

The positive request/wire round trip uses actual historical bytes. Controller installation identity and elapsed clock are explicit host fixtures. Negative cases mutate separate in-memory copies. No phone is connected or queried, no process is signaled, and no Android tool effect is performed.

## Run

Run run_host.py with --source, --parent-source, --java-home, --json-jar, --private-input-map and --output absolute paths. The output must be new and outside both source trees. Example values are /absolute/candidate/source, /absolute/parent/source, /absolute/jdk17, /absolute/pinned/json.jar, /absolute/private/original-map.json and /absolute/new-output.

A passing result records actual source/tool hashes, unchanged full source digests, all original hashes, retained legacy receipt, stages and exact case counts. This proves host protocol admission/rejection, not current phone absence, App recovery, business success or device usability.
