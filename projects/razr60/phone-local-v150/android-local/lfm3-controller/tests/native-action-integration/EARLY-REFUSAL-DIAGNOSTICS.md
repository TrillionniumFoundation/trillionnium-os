This candidate changes one production file and three existing host-test files. It is unpublished and NOT_BOUND. The installed R4/source9c55 and all old receipts remain unchanged. The copied SOURCE-MANIFEST is the unmodified base manifest, not a valid manifest for this candidate; a publication/build freeze must regenerate it later if approved.

The three actual Mi152/153 attempts failed in backgroundBeforeDispatch before a complete fresh graph was read. Their original n16 labels differ across observations, but those are not same-attempt before/fresh pairs. This patch does not permit changing hints or modify a comparison rule.

On the already rejected visible/enabled original target signature, only the existing private Xiaomi open_search ActionGuard may request a best-effort bounded diagnostic. It retains the unequal composite signature hashes and exact child-label facts used in that rejection, then reads a complete graph under the same worker budget, guard, owner, installed identity, task, window and lease. The later census and the rejected refresh are explicitly not atomic or the same instant. Original screenshot provenance is retained; no fresh screenshot is asserted. A complete private record is published only inside the existing 262144-byte limit. Failure, cancellation, expiry, unavailable census or identity mismatch leaves the original refusal in place and supplies no diagnostic approval.

The original stale exception is always thrown after diagnostics. The patch never sets nativeActionRevalidated, nativeActionProof, claims the guard, changes a model action or observation, calls performAction, retries, or touches the main screen. All existing target equality, purpose comparator, live-chain, installed identity, cancellation, deadline and one-effect gates remain intact.

Host tests extract both this exact production diagnostic helper and the exact early background gate. Synthetic Android endpoints explicitly model only a user0 owned background window. They never supply a profile proof or device screenshot. Added cases cover hint mismatch with complete diagnostics but continued refusal; unchanged equality without added reads; wrong purpose; prior record preservation; installed/owner/census/deadline/cancel/closed-guard failures; main display; cancellation during the census; and invisibility. Existing 76 pure comparator cases and all integration cases remain.

This candidate does not implement or claim that rule.
