# Exact seven- or eight-image homepage carousel

This patch accepts only complete continuous advertising0..6 or advertising0..7 sets. Each before/after DOM and full native traversal still has identical membership and unchanged noncarousel content. Native declared children must equal the verified set size. Each child still has exactly one plain image. All prior geometry, action, target, window, lease and task checks remain.

The original eight-only predicate implicitly forced DOM/native cardinality to match. A mandatory DOM-proof argument now preserves this relation at the observation bracket, action permit and final live native recheck. Omitting the argument fails compilation. Mismatched 7/8 counts, missing or duplicate IDs, changed membership, unknown counts and missing proof are rejected.

Only two production Java files change. The existing 36 policy and 20 bracket cases run against the production classes, plus the new count/counterexample suite. Optional original capture raws are read in place and recorded only by SHA/size; none are copied into source or this patch. Pure host tests do not prove Android service authority or successful flight query. Full Android build/device validation remains the integrator's gate.
