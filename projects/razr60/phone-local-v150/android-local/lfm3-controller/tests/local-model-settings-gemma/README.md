# Ordinary Gemma text model entry

This gate reuses the complete existing ordinary settings, runtime generation, visual settings and Qwen entry gates, then executes eight Gemma entry cases through the actual extracted owner buttons, complete LocalModelSettings transaction and text runtime adapter. Android views, process inventory and positive full model verification remain explicit host ports. The real Engine memory and wrong-size negative paths run. Caller-supplied pin fields, unknown models and implicit/CPU devices remain rejected.

No phone, native inference, model download or positive backend/business qualification occurs. The current LFM3 default and automatic target preference policy are unchanged. Import publication and SHA failures are covered by the existing offline-model-import gate; its exact registry includes the two pre-existing pinned Gemma profiles without a projector.

Run run_host.py --source ABSOLUTE_SOURCE --output NEW_ABSOLUTE_OUTPUT --java-home EXISTING_JDK_17 --json-jar EXISTING_PINNED_JSON_JAR. Run the existing tests/offline-model-import/run_host.py with the same arguments separately.
