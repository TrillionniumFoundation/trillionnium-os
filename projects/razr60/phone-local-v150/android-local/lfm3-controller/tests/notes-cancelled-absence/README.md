# Cancelled personal Notes current absence

This gate consumes a private, externally supplied map of the original 50af task,
all 76 task files, nine completed app request receipts, and four original model
generation records. It runs the actual production Request, wire packing, worker
generation validator, client, immutable-file checks, durable archive and exact
journal compare-and-swap. Existing personal Notes policy, display-census, client
and post-model cases run unmodified first.

The two future-state variants (application startup archive and broker EOF-only
successor) are explicitly authored from the real historical bytes. They are not
phone observations. The host client uses Android filesystem, PM, clock and
read-only-helper process ports. Its only historical relocation is the two
absolute generation file paths and the app-session SHA projection that binds
them. The separate pure Request tests use the exact captured bytes, including
all nine full action JSON values, all model outputs, cancellation records and
generation records. A manifest hash cannot replace request semantic validation.

The tests do not execute Android UI acknowledgement, remove a phone task, signal
a phone process, or prove any current phone resource absence. The new typed
recovery retains exit 143, regular receipt invalid, old cleanup unknown and
business failure. A real future recovery still needs two complete fresh native
censuses, unchanged physical and foreign state, the exact old lease CAS, and the
ordinary application acknowledgement. No budget, input authority or old task
result is expanded or rewritten.

Invoke `run_host.py` with `--source`, `--java-home`, `--json-jar`,
`--private-input-map` and a new `--output` directory. The runner pins every private
input, production compile input and tool before and after, and requires strict
Java 8 compilation on the pinned Java 17 toolchain. The original 262144-byte
bundle, 65536-character wire and 60000-byte whole-command bounds stay unchanged.
