# Rejected blank-banner recovery

This gate reads the exact archived b813 action through an explicit
`--actual-action` input. The private phone archive is not copied into this source
tree. The input is pinned at 213701 bytes and SHA-256
`cb97f512faccc62e826157b09181a503abc32c14c53b58fb4fca583e2fcf19ec`.
It is evidence of an old failed action, with `stale=false`, and is never rewritten
as a device success or as an already-authorized recovery.

The real C and D values are passed through the full production Snapshot and
Role classes. The old full-page-plus-partial-edge pair must still be rejected;
the new behavior is a typed refusal which the existing service can consider
for its bounded no-effect read successor. These pure cases do not construct a
live node, service capability, model response or dispatch permit.

Run with the existing Java 17 toolchain and pinned org.json jar:

```sh
python3 -B tests/native-search-carousel-edge/run_recovery_host.py \
  --source /absolute/component/source \
  --output /fresh/outside/source/output \
  --java-home /absolute/jdk17 \
  --json-jar /absolute/json-20240303.jar \
  --actual-action /absolute/archived/b813/step-01-action.json
```

The gate includes the original two-pixel observation, both directions, left and
right edge widths 1, 2, 3, 17 and width minus one, and rejected geometry, metadata,
identity, completeness and multiple-edge boundaries. All geometry mutations
recompute the ordinary complete empty-child reference; invalid geometry is not
merely rejected because its hash is stale. The full-page coverage predicate and
strict/planning/execution Role comparisons must not accept an overlapping pair.

The existing `native-search-producer/run_producer.py` exercises the actual
service no-effect producer, Session, successor read and controller branches with
explicit Android/model IO ports. Its original `ambiguous_banner_wider_overlap`
case retains its name and old zero-effect assertion. Its expectation evolves
from refusing any read successor for two pixels to requiring only the existing
single successor, fresh complete pair and new model decision. The remaining
original scenarios retain their boundaries and are additionally exercised with
two-pixel and width-minus-one edges. Original navigation/chain deadlines,
retirement, drain, same-node, cancellation, replay and successor-count guards
remain in force. A host pass is not a new phone or shopping success.
