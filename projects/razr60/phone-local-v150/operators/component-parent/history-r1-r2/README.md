# Reviewed component parent source

This directory is a public source projection of the exact reviewed r1 and r2 shell scripts. Each code file retains its original bytes and SHA256. PROJECTION.json identifies the original private deployment manifest hashes and the scope of this projection.

The scripts are instance-specific: they contain the owned journal/log device and inode values; r2 also pins the original failed r1 process identities and record names. Those values are part of the reviewed safety gate and are deliberately not replaced with apparent generic values. There are no API key contents, original user text, UI captures or private task bodies in these source files.

This is not an installable deployment. Original SHA256SUMS, private admission/proof/resolution material, tar packages, full process captures and user data are excluded. The scripts require their private fixed inputs before any application is admitted. Do not delete or rewrite a one-use claim or change an old failed task to run this example.

The implementation uses an own-session child admission barrier, same-PID labelled exec, actual post-exec identity/context/credentials checks, exact owned-group signalling, actual wait in the original parent shell and independent group/session censuses. r2 preserves the original r1 failed-start logs and records and writes its new output to a separate new supervisor directory.

The600-second lease begins only after post-exec readiness. Kernel I/O and actual wait are not unconditionally time-bounded; the reviewed deployment also requires an external660-second TERM deadline and20-second cleanup grace. Forced supervisor termination is not proof that its parent or separate worker sessions exited. No startup, task, model or business success is claimed by this source projection.

Actual r6 startup, native component qualification, policy semantics and business acceptance belong to separate immutable evidence and checkpoint reports. The current source projection neither publishes nor changes those reports.
