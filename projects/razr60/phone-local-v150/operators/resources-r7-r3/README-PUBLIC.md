# Resource source boundary

The bounded read-only sampling logic and units are retained. Private boot/process identities, expected-role inputs and host paths are replaced in these review sources. Real EXPECTED-ROLES and phase originals are excluded.

Snapshots can report observed RSS, high-water marks, CPU counters and device values. They are not continuous per-task peaks, energy measurements or proof of daily-use stability. Model usage comes from original response receipts; outcomes are reported separately.
