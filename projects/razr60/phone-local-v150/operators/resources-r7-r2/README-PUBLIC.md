# Resource observation sources

These public copies preserve the bounded read-only sampling logic and measurement units. Instance boot identifiers, private host paths and expected-role inputs have been removed or replaced by placeholders. The actual EXPECTED-ROLES.json and before/after raw observations are private.

A pair of process snapshots can report observed RSS, high-water marks, CPU counters and device values; it is not a continuous peak measurement, energy measurement or proof of daily-use stability. Interpret current model and business observations using the separate quality checkpoint.
