# Host transport source candidate r1 — public review projection

This is a separate host operator source candidate. It carries no new phone, policy-adoption, component, model-health, business, fixed-nineteen or daily-use qualification. The measured r7-r3 checkpoint elsewhere in this project remains historical and unchanged.

## Problem and repair

The original coordinator wrote a potentially large input into a child pipe before publishing child ownership or entering its timed wait. A child that stopped reading could therefore delay the parent beyond the stated wait budget or raise `BrokenPipeError` before a `CHILD` or `UNKNOWN` record existed.

The candidate supplies a checked retained read-only regular file as stdin, stores the actual child handle immediately after launch, shares one monotonic launch-through-join deadline, and closes each parent-owned stream independently. Failures retain child ownership and original observations. Closing the parent's descriptors does not establish remote-child retirement; unknown work is not automatically replayed or signalled.

The policy driver now binds the repaired transport separately from the retained original. Its original historical plan validator and namespace stay intact, while `__file__` identifies the repaired source. Its failure handler uses the same ownership cleanup. The original nonce and output intent were not renewed. This driver uses synchronous transport; the legacy coordinator's unrelated asynchronous `run` entry is outside this integration's qualification.

## Source and privacy boundary

The four `.PUBLIC.py` files are explicit projections of the baseline and corrected transport/driver sources. They replace operational paths, boot/nonce identities, network bindings and private runtime digests with required placeholders. Direct script entry refuses execution. These files are not the private original bytes, a deployment archive, or an installable package.

[PROJECTION.json](PROJECTION.json) maps each original **source artifact** SHA256 to its distinct public SHA256 and records the transformation. The five changed transport definitions retain the reviewed private source AST exactly. Public deltas reconstruct the public projections only; they must not be applied over private frozen bindings. No private plan, request, claim, draft, key, private runtime-binding digest, device log, executable, policy binary or original execution receipt is published.

The existing [public source boundary](../../PUBLIC-SOURCE-BOUNDARY.md) applies. Original source hashes are provenance references; they do not disclose the corresponding private files or make a public projection an original seal.

## Validation and reproduction

Run on a Unix host with Python 3 and Git:

```bash
python3 -I -B tests/test_transport_projection.py
```

The public harness checks exact public source hashes and executes only selected transport AST definitions against synthetic local children. Its 12 checks comprise two reproduced original defects, four repaired transport process cases, two byte-exact public patch round trips, and four direct-entry refusals. Every test child was naturally joined; no signal or automatic replay was used. [HOST-FIXTURES.PUBLIC.json](HOST-FIXTURES.PUBLIC.json) contains the generated public result, with no private device or process identity. These counts are not phone-task samples, model throughput or fixed-nineteen credits.

The separate private driver candidate passed ten local integration checks and independent focused source review. On Mac, both complete original and repaired historical-plan validators returned the same result against the actual retained dependency files, including 24 files in that historical runtime package. That was a read-only compatibility check with zero child starts, phone calls or policy operations. Raw private validation evidence remains excluded, so this statement is a bounded checkpoint summary rather than a publicly replayable private deployment.

No hard wall-clock bound is claimed for input preparation, hashing, filesystem sync, unpreemptible process creation or cleanup. The execution deadline rejects late observed joins; it does not make those OS operations preemptible. The retained input relies on trusted private file ownership, not kernel-enforced immutability against a hostile process with the same UID.
