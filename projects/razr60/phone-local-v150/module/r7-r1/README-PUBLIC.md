# r7 module review-source boundary

These files preserve reviewed module lifecycle logic and source provenance. They are not an installable package. Private key files and content hashes, consumed-claim manifests, original task evidence, sealed bindings, deployment sums, binaries and tar archives are deliberately omitted.

The projection index records every original and public byte hash. Launch-provider substitutes the instance claims digest. The activation census substitutes boot, anchor and retired process identities. Some builder assertions use placeholders for original observed instances. Do not run a projected source as if it were the sealed private operator artifact or recompute its private runtime pins in place.

The exact private module archive is 276950 bytes, SHA256 91a4a30c9b32eba545542ec3a1baa1701447ef8796f092f8f90afdcda4fae220. Its original module manifest SHA is c0e31ecac9168218e7b6a622e4a3df138859743bd83911add42c32906d173a06. These identify retained operator artifacts, not files distributed here. One host build and exact Pocket4 readback exist; no independent bitwise rebuild is claimed, and tar metadata was not normalized for such a claim.

The source changes two provider files, keeps thirteen production Python modules and the original executor, model, policy and limits. Host preparation does not qualify runtime health, business actions, cold boot, fold states or daily use. Later actual observations belong in independent versioned checkpoints; original failures remain preserved.
